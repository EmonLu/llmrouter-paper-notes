# 综述类论文记录模板（Survey 专用）

> 用途：用于记录“大模型路由 / LLM Router / Agentic Routing / 推理成本路由策略”方向的综述、survey、systematic review、taxonomy 类论文。
>
> 和普通方法论文不同，综述类论文的重点不是“某个方法怎么做”，而是：
> - 它如何划分问题空间
> - 它如何组织已有方法
> - 它提出了哪些统一视角、评价维度和未来方向
> - 它是否能帮助我建立自己的研究框架

# 多篇综述横向对比表模板

> 用途：比较多篇 survey / taxonomy / review 论文，帮助你判断哪篇适合做“总地图”，哪篇更适合做“问题定义参考”。

| 综述 | 年份 | 覆盖主题 | 分类主轴 | 是否有统一定义 | 是否有系统框架 | 是否有 benchmark 总结 | 是否讨论部署问题 | 是否讨论 open problems | 是否适合入门 | 主要优点 | 主要缺点 |
|---|---:|---|---|---|---|---|---|---|---|---|---|
| Survey A | 2024 | 多模型路由 | 方法类型 | 是 | 否 | 是 | 否 | 是 | 是 | 框架清楚 | 工程视角弱 |
| Survey B | 2025 | adaptive inference | 系统流程 | 是 | 是 | 部分 | 是 | 是 | 中等 | 更贴近部署 | 覆盖范围窄 |
| Survey C | 2026 | agentic routing | 决策层级 | 是 | 是 | 是 | 是 | 是 | 是 | 很适合作研究地图 | 篇幅大 |
